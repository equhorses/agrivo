# Project Summary
Agrivo is a global agricultural marketplace that connects farmers with agricultural professionals. It supports job publication, professional discovery, bidding, subscriptions, payments, communication, reviews, disputes, and identity verification, with multilingual support for Spanish, English, Portuguese, and French.

# Project Module Description
- **Landing**: Presents the marketplace, agricultural categories, statistics, and featured content.
- **Jobs**: Supports job creation, search, filtering, details, and professional bids.
- **Professionals**: Provides a searchable directory of verified agricultural professionals.
- **Pricing**: Manages subscription plans and Stripe payments.
- **Dashboard**: Lets users manage jobs, bids, subscriptions, and account activity.
- **Authentication**: Handles registration, login, and callback flows.
- **KYC Verification**: Supports post-payment identity verification.
- **Admin Panel**: Manages KYC requests and verification notifications.
- **Messaging**: Enables communication between farmers and professionals.
- **Reviews**: Allows ratings after completed jobs.
- **Disputes**: Provides conflict-management workflows.
- **Downloads and Documentation**: Offers technical files and visual platform documentation.
- **Legal**: Displays terms, privacy, and other legal information.
- **Shared Layout**: Contains reusable navigation, headers, footers, and interface components.
- **Localization**: Provides multilingual interface support.

# File Description Inventory
- **`app/backend/main.py`**: Initializes and exposes the backend application.
- **`requirements.txt` and `requirements.default`**: Define Python dependencies for backend execution and setup.
- **`start_app_v2.sh`**: Automates application startup.
- **Backend modules**: Implement API routing, data access, verification, notifications, messaging, payments, and business rules.
- **Frontend pages and components**: Implement marketplace, account, administration, documentation, and communication experiences.
- **Frontend public assets**: Store static images and downloadable documentation.
- **`image_manifest.json`**: Tracks images used by the frontend.
- **`constants.ts`**: Provides frontend seed data and shared constants.

# Technology Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Router, TanStack Query
- **Backend**: FastAPI, SQLAlchemy, PostgreSQL
- **Payments**: Stripe
- **Email**: Resend
- **Styling**: Custom emerald and teal agricultural theme with Poppins and Inter fonts
- **Backend Dependencies**: Python packages managed through requirements files

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Build the frontend:
   ```bash
   pnpm run build
   ```
4. Start the application using the project startup script:
   ```bash
   cd app
   ./start_app_v2.sh
   ```
5. To download the complete project code from the development chat, use **Share → Export**. To inspect or edit individual files, use the **Editor** panel.
