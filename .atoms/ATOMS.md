# Project Context

## Project Overview
AgroTask World - A comprehensive agricultural marketplace platform connecting farmers with agricultural professionals. Features reverse auction bidding, professional verification (KYC), multilingual support (ES/EN), subscription plans, and real-time messaging.

## Constraints
- Color Palette: Primary green (#166534), Secondary earth (#92400e), Accent orange (#ea580c), Background warm white (#fafaf5)
- Typography: Poppins for headings, Open Sans for body text
- Design: Trust & Authority style with marketplace/directory pattern
- Target: Latin American agricultural market (Argentina, Brasil, Chile, México, Colombia, Uruguay)
- Categories: Fumigación Aérea, Análisis de Suelo, Sistemas de Riego, Topografía, Cosecha, Consultoría, Siembra, Poda, Fertilización, Ganadería
